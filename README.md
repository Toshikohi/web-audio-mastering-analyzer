# 🎛️ Web Audio Mastering Analyzer

ブラウザ上で高精度な音響解析とマスタリング処理を完結できる、クライアントサイド完結型の Web アプリケーションです。

音声ファイルをドラッグ＆ドロップするだけで、周波数スペクトラムやステレオ定位、位相相関などのリアルタイム解析を行いながら、5つのマスタリングモジュール（EQ、コンプレッサー、サチュレーター、ステレオイメージャー、リミッター）による音質調整や、各種フォーマットでの WAV マスター出力が可能です。

## 🛠️ 開発・ビルド方法

Vite と TypeScript によるモジュール構成で開発し、配布用の単一スタンドアロン HTML（`dist/index.html`）へビルドします。

```bash
# 依存関係のインストール
npm install

# ローカル開発サーバーの起動 (HMR)
npm run dev

# 単一スタンドアロン HTML への一本化ビルド
npm run build
```

## 🚀 主な機能

### 1. ビジュアライザー＆音響解析
- **3つの表示モード**:
  - **周波数スペクトラム (Spectrum)**: 低域から高域まで高精細に表示。左右重ね合わせ・上下分割・左右差分表示に対応。
  - **スペクトログラム (Spectrogram)**: 周波数と音量の時間変化をカラーヒートマップでスクロール表示。
  - **オシロスコープ (Oscilloscope)**: 波形のゼロクロス同期による安定したリアルタイム波形表示。
- **ステレオ・ゴニオメーター**: 音像の広がりや定位、位相関係をリサージュ図形としてリアルタイム表示。
- **位相相関＆帯域別バランス**: モノラル互換性の確認や、6帯域ごとの左右エネルギーバランスをメーター表示。
- **ピーク＆True Peak（dBTP）監視**: 瞬間ピークおよび4倍補間によるインターサンプル・ピークを検知。クリップ発生時は警告表示。

### 2. マスタリング・コンソール
- **5つのDSPモジュール**:
  1. **Clean EQ**: 不要な超低域をカットする Low Cut や低域モノラル化（Mono Maker）、トーン＆エアー調整。
  2. **Glue Compressor**: バス全体の音のまとまり感を高める VCA スタイル・コンプレッサー（パラレル Mix 対応）。
  3. **Saturator**: テープや真空管の温かみと自然な倍音を付加するソフトサチュレーター。
  4. **Stereo Imager**: Mid/Side 処理による自然な音場の広がり調整。
  5. **Brickwall Limiter**: 音圧向上とクリッピング防止を両立する高精度リミッター。
- **A/B 試聴機能**:
  - **MASTERING ON/OFF**: マスタリング適用音と原音を瞬時に切り替え可能。
  - **Auto-Gain Match**: 音圧向上による聴感上の音量差を自動補正し、純粋な音質変化を比較可能。
- **内蔵テスト信号**: ドラムパルス、1kHzサイン波、周波数スイープなどのテスト音源をワンクリックで生成・再生可能。

### 3. WAV マスター出力 (Export)
- **自由なフォーマット選択**: 16-bit PCM（ディザ適用）、24-bit PCM、32-bit Float から選択可能。
- **サンプリングレート変換**: 高品質な Sinc 補間とアンチエイリアシングフィルターにより、音質劣化を抑えてリサンプリング。
- **ブランク＆フェード設定**: 頭欠けを防ぐ先頭無音（Lead-in）や余韻を残す末尾無音（Lead-out）、クリックノイズを防ぐマイクロフェードを適用可能。

## 📂 使い方

1. 単一ファイル版の `web-audio-mastering-analyzer.html`（または `npm run build` で生成された `dist/index.html`）をブラウザで開きます。
2. 画面上部の枠内に、解析・マスタリングしたい音声ファイルをドラッグ＆ドロップ（またはクリックして選択）します。
3. 自動的に読み込みと解析が開始され、再生やマスタリング操作、WAVエクスポートが可能です。
